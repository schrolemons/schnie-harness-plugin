# 插件边界与接口契约

index.js注册只读检索、总览与增量工具指引；lib/knowledge-client.js负责必要字段、端点校验、取消、超时、缓存和有界响应；client.js使用DSH支持的会话节点和slot展示当前轮实际引用的来源，不修改宿主代码或模型设置。

POST请求字段仅为operation、query、site、mode。成功响应为schema=1、operation、site、sources，检索来源包含16位十六进制id、title、HTTPS url、text；总览附overview。所有来源都以服务端返回的身份为准，UI不把任意文本中的网址当成检索证据。

没有配置端点时保持可加载但工具明确报错；不进行服务自动发现或备用网络访问。端点参数仅来自部署者配置或DSH_KNOWLEDGE_ENDPOINT，不接受模型工具参数中的地址。输出将未知服务错误转换成通用提示，不将原始上游响应交给模型。

来源缓存仅在插件当前实例内短期使用，不把旧轮的检索记录当成本轮证据。安装、宿主工具暴露、网络检索和模型真正采用资料是不同阶段，应分别验证。
